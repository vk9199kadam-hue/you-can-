# 🎓 YOU CAN - AI-Powered Maharashtra Learning Platform

This is the comprehensive learning suite for Class 11-12 students in Maharashtra, designed for high-performance prep in **MHT-CET, JEE, and NEET**.

## 🏗️ The 3 Compartments

### 📦 Compartment 1: The Content Engine (`/src/data`)
*   **Source:** JEE Mains (HostServer001), NEET Benchmark (Reja1), and MHT-CET Legacy repos.
*   **Schema:** Defined in `educational_platform_data.md`.
*   **Status:** Manifest created. Ready for bulk ingestion.

### 🤖 Compartment 2: The AI Engine (`/src/ai`)
*   **Logic:** LangChain RAG pipelines for resolving complex PCM/PCB doubts.
*   **Features:** Collaborative whiteboard (tldraw) and image-based doubt resolution.
*   **Status:** API shell implemented.

### 🏗️ Compartment 3: Infrastructure & Analytics (`/src/analytics`)
*   **Tracking:** PostHog-powered student progress heatmaps.
*   **Database:** Supabase/PostgreSQL unified question schema.
*   **Status:** Analytics dashboard shell ready.

---

## 🚀 Getting Started (Localhost)

1.  **Install:** `npm install`
2.  **Dev Mode:** `npm run dev`
3.  **Data Import:** Follow the instructions in `educational_platform_data.md` to seed your local database.
